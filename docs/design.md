# daily-log 界面设计系统

本文档记录桌面界面（`desktop/`，基于 `github.com/egoist/mygo` 的 `ui` 包）的视觉与动效约定。
它的目的不是描述"现在长什么样"，而是说明"为什么这样"，让后续任何一处修改都能落在同一套语言里。
参考对象是 `github.com/egoist/mygo-music`：一个同样用 MyGo 原生 UI 绘制、克制而连贯的桌面应用。

## 1. 三条原则

1. **层次来自面，而不是线。** 卡片不投影、不描粗边；"里面还有一层"靠面色的抬升与下沉表达。
   只有浮在应用之上的东西（提示、弹层、对话框）才投影。
2. **一个动作只有一个时长。** 指针悬停是一回事，状态改变是一回事，面板开合是一回事；
   全应用各用同一个值，眼睛才学得会。
3. **界面不因为说话而移动。** 加载、失败、后台任务这些"话"都不占据版面，
   它们浮在页面之上或待在页眉里，出现与消失都不推动正文。

## 2. 面（surface）的阶梯

`desktop/design.go` 的 `palette` 定义了五级面，浅色向下、深色向上，方向相反但读法相同：

| 级别 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `bg` | `#ffffff` | `#131316` | 页面 |
| `sidebar` | `#f2f2f6` | `#19191d` | 侧栏 |
| `surface` | `#f7f7fa` | `#1d1d22` | 卡片、表格 |
| `tile` | `#ffffff` | `#27272d` | 卡片内抬升的块（指标、时段里的条目） |
| `sunken` | `#eff0f4` | `#161619` | 嵌进卡片里的井（时段栏、状态块） |
| `raised` | `#ffffff` | `#2b2b31` | 浮层、表头带 |

（表里是**未上色前的底**：每一级再按 §2.1 掺入色温。）

规则只有一条：**一个块相对它所在的容器，要么抬一级，要么沉一级，不能同级。**
"卡片里套一个带边框的卡片"是被禁止的写法——那等于用线说了两遍同一句话。

发丝线（`hairline`）与边线（`border`）分别是 7%/10% 与 14%/18% 的黑白 alpha；
分组列表用 `Dividers(1, hairline)` 画行与行之间，而不是给每行画框。

边线**只用黑白**：强调色不描边。"这一张是默认项"由面色抬升与一枚药丸说完，
再用有色边框描一遍，等于用线说了两遍同一句话，而且比页面上任何其他一处都很响。

### 2.1 色温：面不是灰的

纯灰是"没人做过选择"的颜色。所以每一级面都朝**当前的强调色**掺一点（`cast`）：
浅色 1%–4%，深色 3%–6.5%，越沉的面掺得越多——光落在近处，角落里留住颜色。
于是换强调色换的不只是按钮的颜色，而是整个房间的色温：`海蓝` 下页面偏冷，`默认` 下偏暖。
文字与 muted 保持中性：读东西不该戴着颜色。

检验：`light-dashboard-sea-blue.png` 与 `light-dashboard.png` 并排看，两次的灰必须能看出是两间房。

### 2.2 光：面的上缘更亮

卡片、工具条、表格的 1px 边不是同一个颜色：`edgeLit` 用一条纵向渐变描它，
**迎光的那条边更亮、背光的那条更沉**（浅色是上淡下深，深色是上亮下暗）。
井（`sunken`）反过来——近端的唇在影子里，远端的底才接到光。
它不改变任何一级的面色，只是让"这块面是某个地方"而不是"这是个矩形"。


## 3. 间距、圆角、尺寸

全部取自 `desktop/tokens.go`，不允许出现新的字面量：

- 间距在四点网格上：`spaceHair(2)`、`spaceXS(4)`、`spaceS(8)`、`spaceM(12)`、`spaceL(16)`、`spaceXL(20)`、`spaceXXL(24)`、`spaceHero(28)`。
  `spaceHair` 只用于"两行是一个意思"的地方（日期与星期、数字与单位）。
- 圆角随面变大：`radiusField(8)`、`radiusRow(10)`、`radiusTile(12)`、`radiusCard(14)`、`radiusSheet(16)`、`radiusPill(999)`。
  控件要么 6–10，要么是整圆；不存在 13、15 这样的中间值。
- 控件高度固定：`heightNav(34)`、`heightChoice(30)`、`heightStatus(24)`、`heightField(32)`、`heightPill(36)`、`heightHeader(40)`。
- 字号按角色取整：**`sizeHero(36)`**、`sizeDisplay(30)`、`sizeFigure(28)`、`sizeMetric(22)`、`sizeSection(19)`、`sizeCardTitle(15)`、
  `sizeField(14)`、`sizeBody(13)`、`sizeMeta(12)`、`sizeSmall(11)`、`sizeMicro(10)`。
  **没有半点字号**（12.5、11.5 之类）：半点是"某处随手定的"，不是阶梯。
  `sizeHero` 比一页的标题还大一级，而全应用只有一处用它：工作台上的那个日期。
  一页最大的字是它的名字，说的是"这里有一张表单"；最大的字是日子，说的才是"这是你的一天"。
- 字重只有四档：400/500/600/700。数字一律 `FontFeatures("tnum")`，让一列数字自己对齐。
- 行高按用途：`leadTight(1.2)` 标题、`leadMetric(1.3)` 数字与其下的一行、`leadBody(1.4)` 正文、`leadLoose(1.5)` 长文。
- 一行字不能被挤到中间断开。`widthDate(150)`、`widthFacts(196)`、`widthMetric(120)` 是几处**下限**：
  一个可自由收缩的列永远不会要求它的行换行，于是日期断在中间、时间竖着一行一个字。
  给这一列它自己的宽度（日期用 `textWidth` 现量），行才会让步，把邻居挪到下一行去。

## 4. 动效词汇

`desktop/tokens.go` 里的动效是全部词汇；新增动效应当先问"它属于哪一类"。

| 名字 | 值 | 管什么 |
| --- | --- | --- |
| `hoverFade` | 120ms | 指针下控件的颜色 |
| `stateFade` | 200ms | 控件自身状态变化（选中、开关） |
| `themeFade` | 200ms，Oklab | 整应用换肤时的颜色 |
| `surfaceFade` | 200ms，含颜色与投影 | 一个面的颜色安定下来 |
| `pressSpring` / `liftSpring` | `ui.Snappy` | 按下时的让位、卡片迎向指针 |
| `disclosure` | 200ms | 面板开合、提示来去——全应用同一个时长 |
| `disclosureMotion()` | 200ms，`Collapse`+不透明 | 沿所在列开合：邻居跟着同速移动 |
| `fadeMotion()` | 200ms，`AfterExits` | 同处一室的新旧交替：旧的走完新的才来 |
| `pageMotion()` | 180ms，`AfterExits` | 页面切换：交叉淡入淡出，没有位移 |
| `popMotion()` | `ui.Snappy`，缩放 0.94→1 | 浮在应用之上的东西：提示、确认框 |
| `riseMotion(at)` / `staggered(at)` | 弹簧 + 每项 30ms 延迟 | 一组卡片一起进场时，逐个稍等一拍 |

三条纪律：

- **开合不淡出文字。** 折叠动作用 `Collapse: true, Opacity: 1`：内容保持不透明，只是被收起来，
  于是字是"滑进去"而不是"消失"。
- **页面切换不位移。** 旧页淡出、新页淡入，谁也不推谁；带 Y 偏移的换页会让整页内容跳一下。
- **骨架屏是页面的形状。** 加载中的页面先画出与成品同尺寸的灰块（`skeleton.go`），
  数据到了原位替换，什么都不动；灰块上有一条与全页同步扫过的光带，
  系统要求减少动效时（`ReduceMotion`）光带停住，只留静止的形。

## 5. 组件的写法

`desktop/design.go` 提供共享构件，页面里不再手写等价物：

- `card` / `cardAt`：一张面，一条发丝线，不投影；`cardAt` 带进场节拍。
- `tile` / `sunken` / `callout`：卡片内的抬升块、井、以及"带颜色的话"（警告、结果）。
- `pageHeader` / `pageHeaderWith`：眉题 + 标题 + 一句说明；页面自己的动作放在页眉右端，
  不放在页面末尾——**一个页面不该滚动到底才能被刷新**。
- `statusPill` / `metricTile` / `emptyState` / `sectionLabel` / `factRow` / `actionRow`。
- 按钮永远**抱紧自己的字**：`pillButton` 带 `Shrink(0)`；直接放进 Column 的按钮会被拉成一条横杠，
  必须包在 `actionRow` 或一个 `ui.Row` 里。
- 图标是 24 网格上 1.75 的描边，圆头圆角；尺寸 13–24。
- 工作台的第二行**按窗口给列数**：两列是它画出来的样子，窗口宽到能容下三张"还称其为卡片"的
  卡（≥1520）时，导出卡并入这一行，而不是把一张卡拉成一半字一半空。两列时它跨满整行。
- 窄到放不下表格的列，就**少给一列**：日记总表在 720 以下不再单列"事项"——展开的行里本来就说一遍。
- `dayRibbon`（一天的时间线）是工作台的签名：一件事项一段，**宽度就是它占用的时间**，
  颜色就是它在别处也代表的那个分类，段与段之间的井是空档。它由证据画成，
  所以少于两件带起止时间的事项时它不出现——装饰没有权利说假话，也没有权利说没有的话。
- 眉题（`TODAY`、`SOURCES`…）用**当前色温的那个强调色**说：它是页面自己的声音，
  也是每一页顶端那一点颜色。正文与说明仍是中性灰，层次靠字号，不靠颜色。
- 侧栏里"在哪个页面"由 `sel`/`selText` 说：浅色给这一行掺一点强调色，
  深色把行抬起一级而让**字**去戴强调色——深色里铺一块饱和的洗色看起来是泥，不是一个地方。

## 6. 提示与状态

- 成功与确认走 `c.Toast`，但由 `toastBand` 画：一枚浮在**页眉之上**的小卡（库把它放在窗口底部，
  而那里正是表格按钮待的地方——一句不能点的话，不该站在要点的地方）。它随页面居中，不随窗口居中。
- 正在加载、后台任务在跑：浮在页面右下角的一枚小牌（呼吸的三个点 + 一句话），`popMotion` 进出。
- 失败：同样浮在右下角的一张卡，带关闭按钮；它不占据版面，所以失败不会把正文推下去。
- **两样话同时说**：任务在跑时传来的失败不会被"正在…"盖住——报告在上，等待在下，叠成右下角的一列。
  只有等待时这一列让指针穿过（它没有可点的东西）；有报告可关时，它才占住自己那块地方。
- 断线重试等需要动作的提示，浮在同一处，按钮抱紧自己的字。

## 7. 检验方式

- `desktop/visual_test.go`：`cd desktop && DAILY_LOG_VISUAL_DIR=/tmp/v go test -run TestVisualSnapshots .`
  把每个页面在浅、深两色下拍成 PNG，用于"看"而不是"想"。
  `desktop/` 是独立模块，所以这条命令必须在它里面跑（写成 `./desktop` 会报"main module does not contain package"）。
  每页还有 420 宽的窄屏一张：版面先在那里挤坏。
- `desktop/anim_test.go`：`DAILY_LOG_ANIM_DIR=/tmp/a go test -run TestAnimationFrames ./desktop`
  拍换页、开合、提示三处动效的帧，并断言提示出现时正文没有移动。
- 既有测试点击的是可见文字与 `c.Key`，所以改名、改键都会立刻被发现。
