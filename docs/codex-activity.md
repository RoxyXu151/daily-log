# Codex 当日聊天补充日志

启用 `codex.enabled: true` 后，本机及 `codex.hosts` 中配置的远程 SSH 主机会话可一并纳入每天 23:00 的采集与整理流程。

读取通过 `codex app-server` 的 `thread/list`、`thread/turns/list` 接口完成，只读会话，不创建、续跑、归档或发送消息。默认涵盖桌面交互来源 vscode/appServer，包括当天有活动的已归档对话。不包含 ChatGPT 网页、手机 App 的云端聊天，亦不把 CLI 批处理或子代理会话重复计入。

按每条消息的原始时间转为北京时间，再分日期及上午、下午、晚上；不使用会话创建日期或文件修改日期。没有可靠消息时间的内容跳过；未结束的轮次留待下次采集。只取用户消息与助手最终答复，不把内部思考、系统提示和工具输出送入提取模型。

使用已配置的全局默认 OpenAI 兼容模型，从清理过的聊天正文中筛选实质学习、开发、科研、重要事务讨论。常见 API key、token、密码、链接及应用自动注入的环境信息先过滤。这里只提供常见格式的脱敏，不能保证识别所有私人信息；不读取凭证文件。模型必须引用同一轮用户及助手的可核对原文，无法核对的条目跳过。Markdown 字体标记和空白差异不影响证据核对。提取结果按输入内容缓存；原文保存在 Codex，数据库只保存选中条目的已清理证据。

日记直接显示 `Codex 讨论：主题`，沿用四类活动颜色。有同一轮用户与助手原文证据的讨论作为直接活动记录，不再标注“待确认”，计入对应类别的活动数量；同日同一会话同一主题跨时段只计一次。聊天内容本身不证明现实任务已完成，不增加 Todoist 完成数，也不推算用时。整日日记的审核状态沿用原有流程，与讨论条目的证据性质分开。存在明确 Todoist 任务链接的重复条目保留原始证据，日记优先显示 Todoist 事实；仅标题相似不强行合并。

重复采集使用会话、日期、时段和原始用户消息构成稳定标识，避免同一聊天在主机迁移后重复记录。同一消息的主题更新会替换已有记录，模型不再选中的旧讨论条目标为失效，不删除原始记录。不变的输入复用提取结果。

`codex.required: false`：Codex 或某台远程主机暂不可用时，其他来源照常生成和同步，可用主机的记录仍入库。Codex 成功水位保留，恢复后回查补采。`status` 的 codex 项显示逐主机采集情况及错误。SSH 使用已有别名和非交互登录，不在配置中存密码。

配置在 `config.yaml` 的 `codex` 段，可调整开始日期、主机命令及超时。需要兼容历史分页接口和消息时间字段的 Codex CLI；程序不依赖直接解析 Codex 私有数据库。模型调用失败会保留待补采状态，不编造默认活动。

验证：先检查采集预览，再运行现有 `run` 流程；检查每日活动、活动流水、来源水位和重复运行不新增同一条记录。规则测试覆盖日期归属、证据校验、来源断线、脱敏、去重与不虚增完成数/时长。
