# 日记事项规则

日记总表、自动生成的上午／下午／晚上正文以及各项导出使用同一份 AI 事项。

1. AI 用类似 Todoist 的格式为每项事务生成单行短标题和具体说明。标题最多 28 字，用动作与对象或明确结果概括。说明写清做了什么、涉及什么，以及证据支持的进展或结果。
2. 每项必须引用已有证据。同一事务的多条证据归并为一项。日历安排、自述讨论和已完成任务按各自的证据口径记录。
3. 对话原文留在证据中。生成结果带有对话标签、复制的原文或超长标题时，程序要求模型重写。仍未通过时，本次整理报错并保留该日期的原正文与待整理标记，下次整理自动重试。

自动整理保留人工编辑和已确认日记。表格中的「活动占比」继续按活动证据统计，详见 [活动占比口径](activity-mix.md)。
